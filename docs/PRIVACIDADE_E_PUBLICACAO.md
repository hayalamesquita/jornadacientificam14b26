# Privacidade e publicação pública

## 1. O que o site coleta

A versão atual não possui:

- login;
- formulário de contato;
- cookies próprios;
- analytics;
- banco de dados;
- envio das respostas do quiz;
- armazenamento de dados do visitante.

O quiz é corrigido localmente no navegador e as respostas desaparecem quando a página é recarregada.

## 2. Autoria dos estudantes

A página exibe os primeiros nomes dos seis autores como assinatura do trabalho escolar.

Antes da publicação pública no GitHub Pages, é recomendável que escola e responsáveis confirmem se essa forma de identificação está de acordo com as autorizações e regras da instituição para divulgação de trabalhos de estudantes menores de idade.

Se for necessário reduzir a identificação pública, é possível usar, por exemplo:

- apenas primeiro nome;
- primeiro nome + inicial;
- “Estudantes do Grupo 3”; ou
- outra forma definida pela escola.

A alteração deve ser feita em `index.html` e, se necessário, na documentação do projeto.

## 3. GitHub Pages

O GitHub Pages publica o site na internet. Por isso, não devem ser adicionados ao repositório dados pessoais desnecessários, documentos internos, telefones, e-mails particulares, endereços, fotos privadas ou arquivos com informações sensíveis.

## 4. Imagens

Antes de substituir qualquer imagem, confirme que ela pode ser usada publicamente. Prefira imagens próprias, geradas para o projeto ou com licença compatível com publicação pública.

## 5. QR Code

O QR Code deve conter apenas a URL pública do projeto. Não inclua dados pessoais no próprio QR Code.
